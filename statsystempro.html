StatSystemPro

Work in progress. This Unity Asset Store package is not yet released. Features, visuals and names may change.

A Unity package for runtime stats, modifiers and resources, with editor tools for inspecting dependencies and tracing calculations.

StatusWork in progressFocusRuntime systems and developer tooling

Core features

A stat layer for gameplay code

StatSystemPro provides the calculation and inspection layer beneath project-owned combat, equipment, progression and UI. Developers can use the runtime C# API directly or author reusable data in Unity.

Runtime stat model

Strongly typed stats expose base, calculated, minimum and maximum values. Batch updates group related changes and defer notifications until completion.

Modifiers and effects

Flat, additive percentage, multiplicative and custom modifiers support calculation layers, timed lifetimes, conditions, stack limits and aggregate, refresh, replace or unique policies. Handles, group IDs, owner IDs and exclusive categories give gameplay code explicit cleanup rules.

Connected stats and resources

Cross-stat modifiers can read values from the same or another stat system. Dependency tracking propagates source changes and rejects circular links. Stat-backed resources cover current health, mana, stamina, ammunition and similar values, with change events for gameplay and UI.

Persistence

In-memory snapshots and built-in JSON serializers capture stat systems and resources. Restore reports surface schema, identity and source-resolution problems, while aggregate saves reconnect supported cross-system links by stable system ID.

Authoring workflow

Stat Catalog assets generate strongly typed enums; reusable Stat Profiles provide per-instance overrides. Catalogs can be exported to CSV and imported through a validated preview, while ScriptableObject effects bundle modifiers for reuse.

Inspection and debugging

The editor browser finds scene systems and indexed project assets. Live values, modifier previews, dependency graphs, Stat Trace, calculation breakdowns and configuration diagnostics make the path from authored data to a runtime result visible.
