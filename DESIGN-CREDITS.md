# Design history

The current charcoal and amber portfolio is a standalone HTML/CSS implementation selected by Philip from three local mockups. It uses Barlow Condensed and DM Sans through Google Fonts.

Earlier versions explored Brittany Chiang’s v4 portfolio composition and Ben Scott’s portfolio as visual references. The earlier Brittany adaptation has been replaced; its MIT notice remains in `licenses/brittany-chiang-v4-MIT.txt` to preserve the repository history. No source code from Ben Scott’s website was copied.

Game imagery and other content sources are recorded in `ASSET-CREDITS.md`.
