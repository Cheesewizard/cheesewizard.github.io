Zombieland: Headshot Fever Reloaded · XR Games

PSVR2 porting

Built for PSVR2.

My main focus was porting the game to PSVR2 ahead of the hardware’s launch as part of the XR Games team. This involved working with Sony representatives through the developer portal to clarify platform behaviour and resolve technical questions. That coordination was part of getting the game ready to ship on time as a PSVR2 launch title.

Reusable save package

Portable progression.

I independently authored the reusable save package for the project. That package later formed the basis for extending save support across Steam, Oculus and Sony on Zombie Army VR.
