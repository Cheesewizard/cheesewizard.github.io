The problem

Support the
player’s setup.

Rocksmith is built around a particular audio path. Modern players often use interfaces, external amp simulation, multiple outputs or want to capture a session. Audio Bridge brings those needs into a focused in-game workflow.

What I built

Three connected
pieces.

01

Audio bridge

Windows-native routing and processing controls connect the game’s signal to the player’s setup, with support for pitch shifting, external amp simulation and recording.

02

In-game controls

A compact overlay keeps the important controls close while the game is running, with clear state and recovery paths for a live session.

03

Practice tools

Note-by-note practice features, currently in beta, help players isolate and repeat difficult passages without leaving the game.

The work

From useful idea
to usable tool.

The challenge was connecting native Windows audio behaviour with an existing game mod framework while keeping the player’s primary interaction simple. The project sits at the boundary between low-level signal routing, game UI and the practical realities of hardware that changes between sessions.

I focused on the bridge itself, the controls that expose it in game and the practice workflow around it. It remains an independent project built on the work of the RSMods community.
