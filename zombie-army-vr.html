Scoring service

Extensible scoring.

Platform integration

Reusable packages.

I extended the save package I had independently written for Zombieland: Headshot Fever Reloaded into a multiplatform package, adding support for Steam and Oculus alongside further features for Sony. I also independently authored a reusable social integration package for those platforms. Multiplayer features, backend setup, leaderboards and friend invites were part of the connected systems work.

Loading and performance

Responsive sessions.

I optimised scene loading to reduce hitching and keep loading animations smooth, moving work to asynchronous paths to avoid blocking the main thread. Profiling identified memory and CPU bottlenecks within tight VR frame budgets.
